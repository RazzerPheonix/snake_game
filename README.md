# snake_game
 Лабораторная работа: Создание змейки на pygame

Минималистичная версия классической аркадной игры «Змейка», реализованная на Python с помощью библиотеки Pygame в одном файле. Управляйте змейкой на сеточном поле, собирайте красные блоки еды и набирайте очки, стараясь не врезаться в границы окна или собственный хвост.

![Скриншот геймплея](screenshot.png)
*(Добавьте в папку с проектом скриншот окна игры с названием `screenshot.png`, чтобы он отображался здесь)*

## ✨ Особенности реализации
* **Сеточная механика:** игровое поле размером `600×600` пикселей разбито на клетки по `20×20` пикселей с небольшими отступами между сегментами для наглядности.
* **Защита от случайного проигрыша:** реализована блокировка разворота на 180 градусов в противоположном направлении движения.
* **Умный спавн еды:** новая еда генерируется строго по сетке и гарантированно не появляется поверх сегментов змейки.
* **Счетчик очков:** отображение текущего счета в реальном времени в левом верхнем углу экрана.

## 🛠 Технологии
* **Python 3** (стандартные модули `sys`, `random`)
* **Pygame** — отрисовка графики, обработка событий клавиатуры и контроль частоты кадров.

## 🚀 Установка и запуск

1. **Склонируйте репозиторий или скачайте файл с кодом:**
   ```bash
   git clone https://github.com
   cd snake-game
   ```

2. **Установите библиотеку Pygame:**
   ```bash
   pip install pygame
   ```

3. **Запустите игру:**
   ```bash
   python main.py
   ```
   *(Если ваш файл называется иначе, укажите его имя вместо `main.py`)*

## 🎮 Управление
Управление осуществляется только стрелками на клавиатуре:
* `⬆️` (Стрелка вверх) — движение вверх
* `⬇️` (Стрелка вниз) — движение вниз
* `⬅️` (Стрелка влево) — движение влево
* `➡️` (Стрелка вправо) — движение вправо
* **Закрытие окна (`✖`)** — выход из игры

## ⚙️ Настройка параметров
Вы можете легко изменить сложность и внешний вид игры, отредактировав константы в начале файла:
* `WIDTH, HEIGHT = 600, 600` — ширина и высота игрового окна в пикселях.
* `CELL_SIZE = 20` — размер одной клетки (шаг змейки и размер еды).
* `FPS = 10` — скорость игры (количество шагов змейки в секунду).
