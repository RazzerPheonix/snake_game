# snake_game
 Лабораторная работа: Создание змейки на pygame

Классическая аркадная игра «Змейка», написанная на Python с использованием библиотеки Pygame. Управляйте змейкой, собирайте еду, набирайте очки и старайтесь не врезаться в стены или собственный хвост

![Скриншот игры](assets/screenshot.png)

## ✨ Особенности
* обычное управление и классическая игровая механика.
* Подсчет текущих очков.
* Змейка растёт по мере поедания еды.

## 🛠 Технологии
* **Язык:** Python 3.14+
* **Библиотека:** Pygame 2.5+

## 🚀 Установка и запуск

1. **Запустите игру:**
   ```bash
   python main.py
   ```

## 🎮 Управление
* `⬆️` — Движение вверх
* `⬇️` — Движение вниз
* `⬅️` — Движение влево
* `➡️` — Движение вправо
